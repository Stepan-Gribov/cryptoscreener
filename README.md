# Crypto Screener

Дашборд на Python и Streamlit для поиска программ стейкинга и промоакций на KuCoin, Bybit и Gate. Для выбранного токена можно найти бессрочные фьючерсы на разных биржах и сравнить ставки финансирования при оценке хеджа.

- Вкладки Fixed Earn и Launchpool показывают доступные предложения каждой биржи.
- Вкладка CoinMarketCap показывает рынки бессрочных фьючерсов по выбранному токену.
- При обновлении дашборд сохраняет снимок таблицы локально и отдельно записывает новые строки. Можно обновлять данные вручную или по расписанию в боковой панели.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
python -m streamlit run app.py
```

Ключ CoinMarketCap нужен для поиска фьючерсов, а реквизиты KuCoin — для вкладки KuCoin Fixed Earn. Остальные источники можно открыть и обновлять без этих ключей. Снимки хранятся в локальной папке `logs/`.

Получение данных зависит от доступности API и формата ответов бирж. Дашборд собирает и показывает информацию, заявки через него не отправляются.
